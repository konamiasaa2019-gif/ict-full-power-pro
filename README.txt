ICT FULL POWER PRO - PWA prototype

This is an installable web-app prototype, not an APK. To install it as an app on Android, the files must be hosted on an HTTPS site (for example GitHub Pages), then open the site in Chrome and choose Install app / Add to Home screen.

Current status: demo-only simulated candles and simplified educational pattern checks. No live HFM/Exness connection. No real trading signals. Never trade using demo values.
